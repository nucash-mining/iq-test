# High Range IQ Test

A 48-item timed reasoning test with a Matrix theme. Plain HTML, CSS and JavaScript, no build step.

- **Matrix Reasoning** (16): Raven-style 3×3 figure puzzles, generated in code with balanced answer options
- **Number Series** (8)
- **Verbal & Logical Reasoning** (12)
- **Extended Range** (12): very hard items for scores above 150

Scores use a 3-parameter item response model (expected a-posteriori ability, mean 100, SD 15). Range 40–209. The items have not been normed on a population sample, so results are estimates, not a clinical score.

Progress saves in your browser and the clock pauses when you leave the tab.

Run locally: open `index.html`, or `python3 -m http.server` in this folder.
